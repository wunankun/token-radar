# APIVAI（apivai.com）

- **站点**：APIVAI · apivai.com（API 域名 `api.apivai.com`，Anthropic 格式在根路径，OpenAI 格式在 `/v1`）
- **结算**：**美元**，预付余额按 USD 计费；不是「1 元 = 1 美元额度」的站。支付宝/微信以人民币收款，按当日汇率折成美元余额（服务条款第 3 条），换汇与通道成本已含在汇率里
- **来源**：`https://apivai.com/pricing` 与 `https://apivai.com/api/pricing`（2026-11-27 抓取；页面与接口 `updatedAt` 都标注 2026-11-18）；补充 `https://apivai.com/llms.txt`、`https://apivai.com/terms`
- **账户档位**：无订阅、无充值档、无分组，所有用户同一张价目表。每把 key 需从余额分配预算（最少 $2），请求从 key 预算扣
- **最低充值**：$10（卡 / 加密货币）或 ¥20（支付宝 / 微信支付）

## 分组倍率

无分组，单一价目表（`/api/pricing` 返回的是最终价，不是 `model_ratio`）。

按官方价反算的档位（2026-11-27，仅供理解，不入库）：

|---|---|---|
| Claude 全系 | 约 0.375–0.40× | 各模型略有差异，非统一倍率 |
| GPT 全系 | 约 0.15× | 同一站内比 Claude 线更便宜 |

## 计费方式

- 类型：按量，input / output / cache write / cache read 分别为美元单价（USD / 百万 token），无 `tiered_expr`
- 一次 key 同时支持 Anthropic Messages（`POST /v1/messages`）与 OpenAI（`POST /v1/chat/completions`、`/v1/responses`）
- 定价页写明「价格不随负载变化；改价先改页面和日期」

## 充值

- 单次充值满 $50（任何付款方式，支付宝/微信按折合美元计）额外送 30% → 充 $50 得 $65
- 赠送部分计入余额额度，但不改单价（榜单按项目口径只单列「充值」，不折进价格）
- 未消费余额可在购买后 30 天内酌情退；已消费不退
- 可开中国增值税发票（普票 / 专票），控制台申请，3 个工作日

## 缓存

- 缓存写：约输入价的 1.25 倍
- 缓存读：约输入价的 5%
- 站上 `cacheWrite` / `cacheRead` 单独标价，未套用官方比例，按页面数即可

## 坑

- **全站美元结算**：人民币实付随汇率浮动。榜单按 config 汇率折算，支付宝/微信实际到手汇率含通道成本，真实人民币成本会略高于表中数字。
- **Claude Haiku 5.5 比官方还贵**：站点自己也标「—」不写节省。录价时照站价，不修正。
- **GPT-5.6 Sol 的输出倍率与同站其他 GPT 不一致**（输入约 0.15×、输出约 0.18×），疑为单独档位或标价笔误；按站价录入，未做修正。
- 无免费额度；预付余额不可透支，余额用尽请求直接报错。
- 60 RPM / key 的默认限速，Claude Code 类高并发场景需要多把 key。
